\begin{abstract}
This report provides the comprehensive replication guide and technical documentation for the complete Dutch Collective Labour Agreements (Collectieve Arbeidsovereenkomsten, CAOs) pipeline. The system encompasses five integrated stages: (1) PDF scraping and multi-method extraction (p1--p5); (2) deterministic salary parsing replacing earlier stochastic LLM ladders with a 100\% amount provenance guarantee across 359,474 salary rows; (3) an audited 34-layer non-salary correction and verification framework (G0$\rightarrow$G33) resolving extraction errors against English-translated source text; (4) a derived generosity scoring and wage indexing engine producing pooled-z indices, statutory floor adjustments, and a monthly CAO panel; and (5) a fully automated verification test battery ensuring exact numerical reproducibility.
\end{abstract}
