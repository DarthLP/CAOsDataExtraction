# CAO Descriptive Summary

This folder is **derived and fully regenerable** — nothing here should be hand-edited except the
prose in `General.tex` / `Non-Salary.tex` / `Salary.tex` / `Indices.tex` and the scripts under
`scripts/`. Every table, figure, and inline number is produced by a script from the data listed
below; delete the folder and re-run `scripts/run_all.sh` to reproduce it (modulo timestamps).

## Data sources

| Section | Source |
|---|---|
| General, Non-Salary | `qa/corrected_dataset.csv` |
| Salary | `CAOsDataExtraction/outputs/parser_salary/extracted_data_salary_v2.csv`, filtered to `confidence_tier` A+B (deterministic table parser; not covered by any QA correction layer) |
| Indices | `indices/out/{composite_index,all_indices_panel_monthly,mw_indices,statutory_index,factor_loadings_overall,coverage_vs_z_correlations,statutory_response_results}.csv`, `indices/review/all_open_cant_tells.csv` |

## Rebuild

```bash
cd Reports/Analysis
bash scripts/run_all.sh
```

Runs `01_general.py` → `02_non_salary.py` → `03_salary.py` → `04_indices.py` (each recomputes its
figures/tables/macros from the sources above), then compiles `main.tex` twice with `xelatex`. Step 3
regenerates all ten salary figures from the parser-v2 data and takes ~15 minutes; pass `--skip-plots`
to `03_salary.py` directly when iterating on prose only. Requires `python3` with
pandas/numpy/matplotlib, and a TeX install with `subcaption`, `float`, `geometry`, `booktabs`,
`caption` (all standard in a full/basic TeX Live).

## Layout

```
main.tex, General.tex, Non-Salary.tex, Salary.tex, Indices.tex   # report source
figures/            # PNGs, regenerated by the scripts
tables/             # generated .tex fragments (macros.tex + tab_*.tex), \input by the sections
scripts/            # one script per section + common.py (paths, macro/table emitters, plot style)
main.pdf            # compiled output
```

Every inline statistic in the prose is a `\providecommand` macro from `tables/macros.tex`, and every
`tabular` is `\input`-ed from `tables/tab_*.tex` — no number in this report is hand-typed; each has a
one-line trace back to the script and CSV that produced it.

## Known caveats carried into the report

- Pension generosity is available-case only (blanks = fund-level deferral, never zero-filled).
- The Top/Bottom CAO ranking (Table 6) excludes documents scoring on fewer than 8 of the available
  topics or flagged `thin_doc` — see the note above that table for the exact exclusion count.
- Salary and non-salary/indices come from different, independently-built pipelines; the QA claims
  for one do not transfer to the other.
