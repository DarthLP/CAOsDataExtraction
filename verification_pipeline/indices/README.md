# CAO Summary Indices — v2 methodology

> **Why we do it this way (primary rationale): [METHODOLOGY.md](METHODOLOGY.md)** — z formula,
> the two scales (z + equal-range `gen01`), the two tracks (magnitude + coverage), statutory
> floor, zero-fill, per-topic field/boolean inventory, and the **Decision Log** (append to it
> on any modelling change). Multivariate results: [ADVANCED_ANALYSIS.md](ADVANCED_ANALYSIS.md).
> Catalogue of outputs + headline findings: [INDICES_OVERVIEW.md](INDICES_OVERVIEW.md).
> Design decisions for the v2 redesign: [INDICES_V2_PLAN.md](INDICES_V2_PLAN.md).
> v1 (within-year z, ingangsdatum axis, yearly panel) is fully archived in `_old_v1/`.

All indices are **derived analytical products**, not part of the QA-correction pipeline —
they read the corrected data and emit CSVs here. Nothing writes back to `inputs/`,
`qa/corrected_dataset.csv`, or any corrections file.

## Directory layout (2026-07-15 reorg)

`indices/` root keeps only code (`*.py`, `rebuild.sh`), docs (`*.md`), and `all_indices.xlsx`.
Data files live in one of three subfolders (see `index_lib.py`'s `OUT`/`CORR`/`REV` constants
and the `locate()` reader helper):

- **`out/`** — pipeline-REGENERATED outputs: every `<topic>_index.csv` + diagnostics, panels,
  `composite_index.csv`, `mw_indices.csv`, `statutory_*.csv`, factor-analysis CSVs, etc.
  Safe to delete and rebuild via `rebuild.sh`.
- **`corrections/`** — the audit trail: every applied correction-campaign log (`*_applied.csv`,
  `l21..l31_*`, `dip_*`, `topicsweep_*`, `tierA_corrections_applied.csv`,
  `jump_campaign_adjudications.csv`, `corrections_log.xlsx`). Never regenerated; historical record.
- **`review/`** — hand/agent-curated review queues & registries that are READ but not
  regenerated by the pipeline (`thin_docs_reviewed.csv`, `cao_workweek.csv`,
  `statutory_timeline.xlsx` — Hanna's ground truth — and various `*_review.csv`/`*_proposed.csv`
  diagnostic files).

`_old_v1/`, `.bak_rename/`, `_recovered/` are untouched historical archives at the root.

## The v2 construction, step by step

1. **Time axis** — `file_date = datum_kennisgeving` (the document's edition/publication
   date, 2,738/2,739 populated; 1 fallback to `ingangsdatum`, flagged). Chosen because
   `ingangsdatum` is term-level and constant across a term's republications, so mid-term
   updates were invisible on it. `pub_lag_months` (file_date − ingangsdatum) is exported
   as a diagnostic. `doc_is_newest` = latest file per CAO by file_date.
2. **Cardinal value per field** ("full" variant, unchanged from v1): normalise to the
   canonical unit → plausibility clamp → within-CAO forward-fill (ordered by file_date;
   blank in a newer full doc = unchanged) → era-aware statutory floor/default imputation →
   statutory cap. A "raw" variant (none of the above except unit+clamp) ships alongside.
3. **Pooled z (the v2 core)** — each field is standardised ONCE against all documents of
   all years pooled: winsorise at the pool's 1st/99th percentile, z-score, clip ±3, apply
   the field's worker-generosity sign. **Yardstick de-dup:** the winsor bounds and μ/σ are
   computed on one document per `term_group` (= cao|ingangsdatum, latest edition), then
   ALL documents are scored — reprint-frequency can't bias the yardstick. Parameters are
   persisted in `out/scoring_params.csv`. `topic_z` = available-case mean of the field z's;
   a pool-ECDF percentile rank (`_pctile`) is the robustness companion.
4. **Coverage** — share of the topic's generosity booleans (structural flags excluded)
   + pooled coverage z. Leave now has coverage too (12 booleans).
5. **Leave** — OECD full-rate-equivalent weeks (duration × payrate) across maternity/
   paternity/adoption/parental, with the era-correct statutory floor (era = file_date);
   `leave_z` = pooled z of the with-statutory package.
6. **Wage** — the parser dataset melted to wage points (tier A+B; adult — youth scales
   excluded; entry scales separate; units normalised to EUR/month, hourly only with a known
   hours basis; exact duplicates across editions dropped), aggregated per (cao, year of the
   wage table's own effective date): p10/p25/p50/mean/p75/p90 ladder = the label-free
   skill split, plus WML ratios. `wage_rel_z` (mean/WML) is the cross-time comparable
   wage dimension used in the composite and panel; a labelled worker-type table is a
   partial secondary view.
7. **Statutory index** — for each month, the era-correct statutory floors/defaults are
   scored with the persisted pooled parameters: the law as its own file, on the same
   yardstick (leave, contract, overtime, wage; the other topics have no scalar statutory
   package — nothing is invented).
8. **Composite** — per document: `overall_z_mean` (equal-weight, available-case over the
   10 generosity dimensions) and `overall_z_var` (variance across them = lopsidedness).
9. **Monthly panel** — cao × month; the file in force in month m = latest file_date ≤ end
   of m (a new file "rounds up" and owns its publication month; same-month ties → later
   file). Scores are constant while a file is in force; wage joins per calendar year;
   `STATUTORY` pseudo-CAO rows included; `is_stale` marks in-force files > 48 months old.
   `out/panel_aggregates_monthly.csv` = per-month cross-CAO mean/variance of every z.
10. **Factor analysis** — varimax FA per topic (per-field z's) and overall (10 topic z's);
    data-poor topics skipped. See `FACTOR_ANALYSIS.md`.

## Reading caveats (before quoting a number)

- **Blank vs imputed vs zero-filled** magnitude cells: decision table in `METHODOLOGY.md` §7.2.
  A blank becomes a number ONLY when a statute guarantees it or a presence boolean confirms absence.
- **Pension is available-case only — blanks are NEVER imputed** (`METHODOLOGY.md` §7.1). Blanks mean
  the terms are deferred to a mandatory sector fund (bpf), not that there is no pension; a large part
  of pension generosity is set by the fund and is invisible to the CAO-text extractor.
- **Multivariate analyses run on document-editions, not deduped terms** → read Bartlett/KMO
  descriptively; and **z-rank ≠ pctile-rank within a topic** by design (`METHODOLOGY.md` §11.1).

## Conventions that carry over from v1 (unchanged)

- **empty ≠ zero**: blanks are statutory-baseline (imputed era-aware, where a floor exists),
  fund-deferral (pension — never imputed), or genuine absence (no-anchor topics → coverage).
- **Available-case aggregation** — no false zeros; `n_fields_pop` + `low_support` flag thin rows.
- **Never invent values** — statutory numbers come from `build_statutory.py`'s reviewed
  DATA/WML lists; hourly wages without an hours basis are dropped, not converted by guess.
- **Determinism** — every script re-runs byte-identical; verify with `diff` after changes.
- **FUSE/iCloud mount** — read via `index_lib.read_csv_safe` (raw os.read); trust content,
  not `ls` sizes.
